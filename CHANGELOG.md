# Changelog

All notable changes to this project are documented here.

## Unreleased

### Added

- Light and dark theme toggle with no-flash bootstrap.
- History gallery with autosave, restore, and clear actions.
- Shared nested confirmation dialogs.
- Reusable dismiss-on-outside-click hook.
- License, contributing, security, and code of conduct docs
- Documentation site at `/docs` with sidebar, search, breadcrumbs, and full guides.

### Changed

- Split large components so no source file exceeds 180 lines.
- Moved pure JavaScript logic out of `.jsx` files into `.js` modules.
- Matched preview and code panel dark backgrounds to block cards.
- Replaced em dashes with plain hyphens in copy and docs.

### Fixed

- Onboarding tour theme import path.
- Dark theme text contrast in user account and history gallery.
