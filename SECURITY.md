# Security Policy

## Supported versions

Security fixes are applied to the latest code on the default branch.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
by emailing the maintainer or using GitHub Security Advisories on
[bilalmlkdev/readmade](https://github.com/bilalmlkdev/readmade).

Include:

1. Description of the issue and its impact.
2. Steps to reproduce or a proof of concept if available.
3. Affected browser or environment details.

You will get a response as soon as possible. Please allow reasonable time for a
fix before any public disclosure.

## Scope notes

Readmade stores workspace data in the browser only. It does not run a backend
database for user content. Issues involving third-party services or dependencies
should include the relevant package and version when known.
